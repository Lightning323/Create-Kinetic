# Create Kinetic
An addon mod for Simulated and Create Aeronautics! Adds missing functionality like tracks, thrusters and joysticks.

[Modrinth](https://modrinth.com/mod/create-kinetic), [Curseforge](https://www.curseforge.com/minecraft/mc-mods/create-kinetic)

## Contributions
Contributions are welcome, pull requests should follow the following format
* Clearly state what you are changing
* Ensure the code runs and is in working order (I won't accept broken code)

I merge pull requests within 7 days of opening a PR. If I forget, just DM me on Discord

If you are wanting to contribute to the project directly, DM me and I can add you to the repository.
